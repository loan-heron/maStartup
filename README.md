# FrigoFlash

Prends ton frigo en photo, reçois 3 recettes anti-gaspi. Projet d'école, app mobile en HTML/CSS/JS, entièrement réalisée avec l'IA.

- `da/` : direction artistique (charte `da/02-direction-artistique.md`, `da/styleguide.html`, `tokens.css`, `components.css`, logo, illustrations, maquettes).
